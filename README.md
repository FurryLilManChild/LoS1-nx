# LoS1-nx

A native PC and Nintendo Switch port of Castlevania: Lords of Shadow (Xbox 360), made with
[ReXGlue](https://github.com/rexglue/rexglue-sdk) static recompilation, following
[mof-nx](https://github.com/FurryLilManChild/mof-nx) and [sa2-nx](https://github.com/ChanseyIsTheBest/sa2-nx).

No game data is in this repository: you need your own copy of the game (both discs).

Status: early. See [docs/progress-log.md](docs/progress-log.md) and [docs/scan.md](docs/scan.md).
